# nvim

Configuration for [Neovim](https://neovim.io/).

- `init.vim` - editor options, Russian-layout `langmap`, keybindings, plugin list, a Tre Cime highlight/lualine/toggleterm setup in Lua, and CoC completion mappings.
- `plugged/` - plugins installed by [vim-plug](https://github.com/junegunn/vim-plug): lualine.nvim, nvim-web-devicons, nerdtree, coc.nvim, vim-devicons, toggleterm.nvim, catppuccin, vim-airline and vim-airline-themes. They belong to their respective authors and are not modified here.

Install: copy this folder to `~/.config/nvim`. Run `:PlugInstall` to reinstall plugins instead of using the bundled `plugged/`.
