# fastfetch

Configuration for [fastfetch](https://github.com/fastfetch-cli/fastfetch), a fast system information tool.

- `config.jsonc` - Void Linux logo and a module list recolored with the Tre Cime palette (the same one used by foot, waybar, rofi, qutebrowser, nvim and the GTK theme).

Install: copy `config.jsonc` to `~/.config/fastfetch/config.jsonc`.
