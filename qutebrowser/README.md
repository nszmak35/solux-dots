# qutebrowser

Configuration for [qutebrowser](https://qutebrowser.org/), a keyboard-driven, vim-like browser.

- `config.py` - Tre Cime colors for the statusbar, tabs, completion, downloads, hints, messages, prompts and menus; paddings and fonts; Brave Search as the default engine and start page; `q`/`w` bindings for closing/restoring tabs; preferred dark color scheme for websites.

Install: copy `config.py` to `~/.config/qutebrowser/config.py`.
