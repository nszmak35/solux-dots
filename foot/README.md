# foot

Configuration for [foot](https://codeberg.org/dnkl/foot), a fast and lightweight Wayland terminal emulator.

- `foot.ini` - font, padding, hide-mouse-when-typing and the Tre Cime dark color scheme (foreground, background, 16 ANSI colors, selection and URL colors).

Install: copy `foot.ini` to `~/.config/foot/foot.ini`.

## Font

These configs use **Libertinus Mono**, part of the [Libertinus](https://github.com/alerque/libertinus) font family by Khaled Hosny and contributors (maintained by Caleb Maclennan), licensed under the SIL Open Font License 1.1. Releases: https://github.com/alerque/libertinus/releases
