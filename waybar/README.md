# waybar

Configuration for [Waybar](https://github.com/Alexays/Waybar), a highly customizable Wayland status bar.

- `config.jsonc` - a floating bar at the bottom with dwl tags, window title and layout, clock, keyboard layout, battery, network, power button and tray. Buttons call `rofi`, `pavucontrol`, `nm-connection-editor` and `soluxctl`.
- `style-5.css` - Tre Cime styling: square, fully opaque modules.

Install: copy this folder to `~/.config/waybar`.
