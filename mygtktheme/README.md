# mygtktheme (greymon)

A dark GTK 3 / GTK 4 theme with square controls, built on the Tre Cime palette so GTK apps match foot, waybar and the rest of the setup.

- `index.theme` - theme metadata.
- `gtk-3.0/gtk.css` - GTK 3 styling (includes compact list rows for apps such as nwg-look).
- `gtk-4.0/gtk.css` - GTK 4 / libadwaita styling.

Install (for [nwg-look](https://github.com/nwg-piotr/nwg-look)): place this folder as `greymon` in `/usr/share/themes` (or `~/.local/share/themes`), then pick **greymon** in nwg-look. See `README.txt` for the palette.
