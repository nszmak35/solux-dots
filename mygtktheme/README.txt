greymon
=======
GTK 3/GTK 4 dark theme.

Palette:
background #14171D
surface    #1C2027
surface2   #2A2F38
text       #D2D3CE
subtext    #9C9E9E
accent     #8A9FAD
accent2    #8A9FAD
border     #596070
red        #AB8E89
green      #84916A
yellow     #B0A883

Install for nwg-look:
    sudo mkdir -p /usr/share/themes
    sudo unzip -o greymon.zip -d /usr/share/themes

Then restart nwg-look and select greymon.
